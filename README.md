# Vidly

Vidly is a *vibe-coded* web application which have purpose to manage digital media inside object storage providing metadata over them for discoverability and exposing access to them through a web interface. It was done to kill some time of mine and it's somewhat unexpected if anyone beside me will ever use it.

If I would decide to maintain and develop it further I would be happy to use it as homemade replacement inside my homelab if it would satisfy my needs.
